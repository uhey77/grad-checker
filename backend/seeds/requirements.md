# CS学部4課程の卒業要件マスタ

本書のCSシードは既存IDを保持して先に投入する。


2026年度学生便覧の冊子94（PDF96）の先進情報・社会情報の卒業要件表と、
冊子53（PDF55）の他学部他学科開講専門科目の規則を、2026年10月16日に画像で照合した。
原本のSHA-256・表の各行・小計・合計・注記は `cs_requirements_2026.source.json` に保持する。
既存の `cs_2026.json` と同じ原本であり、科目・分類・課程IDは変更しない。

## 対象と件数

先進情報専攻の情報基盤・人間情報・人工知能の3コースと社会情報専攻が対象。
各課程20条件（総単位1、区分合計3、必修集合3、選択必修群8、内訳最低2、選択合計3）を持つ。

| 内容 | 件数 |
| --- | ---: |
| 卒業要件 | 80 |
| 要件の対象集合 | 492 |
| 算入規則 | 16 |
| 選択必修の換算対象科目 | 265 |
| 他学部科目の共通上限 | 4 |

両専攻とも総必要124、区分合計は実学基礎38・専門基礎42・専門教育44。
専門基礎の必修は先進情報21・社会情報18、選択必修は先進情報18・社会情報21。
数理・マネジメント・コンピュータ／ビジネスの選択必修は、それぞれ4/2/12と2/4/15。
人文2・社会2の内訳最低値も独立した条件として保持する。
表の横線は転記内ではnullのままとし、架空の最低条件を作らない。

## 集合と規則の意味

- `total`・`classification_total` の対象は分類集合。子分類の科目を含む。
- `required_courses` は該当区分の全必修科目ID、`selective_group` は各群の選択必修科目IDを列挙する。
- `subminimum` は親の選択必修群に含まれる科目IDの部分集合。別群の余剰では補わない。
- `elective_total` の分類は直接選択・超過換算・他学部算入の算入先を表す。
  対象分類の全修得単位をそのまま選択単位として合計する意味ではない。
- 親子の対象は重なってよいが、独立した選択必修群の対象は重複させない。
  総単位を条件の値の単純加算で求めない。
- `selective_overflow` は列挙した本人課程の選択必修科目を、同じ最上位区分の選択へ換算する規則。
  群の必要単位と内訳条件は要件集合を参照する。換算量の計算は後続の判定処理で実装する。
- `other_faculty` は1課程1規則とし、すべての算入先に共通する上限6を1行に保持する。
  区分ごとに6ずつ算入する規則ではない。対象他学部科目は未転記のため空。大学の正式な配分順序は未確認のまま、合意したアプリ方針をallocation_policyに保持する。

## 確認状態

カリキュラムの適用入学年度は既存の `unverified` / nullのまま。
卒業単位表の転記完了は、特定の入学年度への適用確認や卒業判定対応完了を意味しない。

実学基礎の超過換算は冊子94注1・注2の再確認によりverified、revision 2へ改訂した。
超過分の選択算入と、人文・社会の各2単位は独立して評価する。
超過換算12規則はverified。他学部4規則は正式な配分順序と対象科目整備を未確認として保持し、
allocation_policy=chronological_best_fit_v1、revision 2でアプリの計算方針を明示する。
取得順・同時期の要件充足を優先する配分と注意表示の詳細は判定ロジックを参照する。

## 再生成・投入

リポジトリルートで実行する。通常の開発DBを変更する操作なので、検証には `DATABASE_URL` でテストDBを指定する。

```sh
task backend-requirements-build  # 転記と既存科目シードからJSONを再生成
task backend-seed               # 課程・科目マスタを先に投入
task backend-requirements-seed  # 要件・規則マスタを追加投入
```

同名のMakeターゲットも使用できる。CLIは `backend/` から
`uv run --locked python -m apps.cli seed-requirements --file seeds/cs_requirements_2026.json`。
トップレベルは上表に対応する5配列を必須とし、未知フィールド・不正UUID・非整数単位・課程外参照・
空の対象集合・親子不整合・群の重複・必修小計不一致・別区分への超過換算を拒否する。
既存DBのマスタと追加分を合わせて検証する。

投入は1トランザクションで行い、失敗時は全件取り消す。同一内容はスキップ、既存IDの変更は拒否する。
省略した既存行は削除しない。通常シードは既存行を変更しない。起動時・投入CLIのスキーマ初期化時に、旧CS2026の既知8規則と全フィールドが一致する行のみ改訂する。独自編集された行は更新しない。
通常起動はテーブルだけ生成し、自動投入しない。

判定処理・判定API・画面・おすすめ・履歴はこの実装に含まれない。
`test_requirement_data.py` で便覧の固定値、再生成一致、参照と集合、DB制約、再投入、途中失敗の原子性、CLIを検証する。

後続でPythonの共通判定関数を追加した。必修・選択必修・内訳・直接選択・確認済み超過換算を
計算する。実学基礎の超過換算は今回の原本再確認で確認済みに改訂した。現在は2026年度便覧を判定基準に使い、
このシードのカリキュラムをunverifiedのまま判定できる。適用入学年度の確認状態のみでは停止しない。判定APIまで追加済み。判定画面も接続済み。他学部の配分処理は対応済みだが対象科目の転記は未完了。おすすめ・履歴は未実装。
