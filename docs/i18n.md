# 日本語・英語の表示仕様

認証・所属・ダッシュボード・成績入力・卒業／修了判定・履歴・開発用科目一覧のUIを日本語と英語で表示する。大学の公式データは翻訳せず、原文を保持する。

## 言語の決定と保存

1. `grad-checker.language.v1`の保存値が`ja`または`en`なら、その選択を使用する。
2. 保存値がなければ`navigator.languages`の優先順で最初の日本語／英語を使用する。`en-US`や`ja-JP`は基底言語へ揃える。
3. 対応言語がなければ日本語を使用する。

ヘッダーの「日本語 / English」で変更し、選択言語だけをlocalStorageへ保存する。初回の自動判定では保存しない。localStorageの取得・読取り・書込みが拒否されても画面は起動し、そのタブ内で切り替えられる。認証情報・復旧コード・入力内容は保存しない。

切替でフォームを再生成しない。入力値、未保存の成績、検索、課程選択、本人申告の回答を保ち、表示中のエラー・通知も翻訳する。`html.lang`とページタイトルを更新する。日時は選択言語の書式を使い、タイムゾーンは閲覧環境に従う。

## 翻訳の配置と境界

| 場所 | 役割 |
| --- | --- |
| `frontend/src/i18n/en.ts` | 日本語のUI文言をキーにした英語リソース |
| `frontend/src/i18n/createI18n.ts` | 初期言語の決定、i18next生成、選択の保存、ページ属性更新 |
| `frontend/src/i18n/setup.ts` | ブラウザーの言語・ストレージ・Documentを渡す |
| `frontend/src/i18n/messages.ts` | 原文で保持した検証メッセージの翻訳 |
| `frontend/src/apps/web/components/LanguageSwitcher.tsx` | 認証前後で共通の切替操作 |

UIは`useTranslation`の`t`を使用する。日本語のリソースはキーから生成し、キーの区切り解釈は無効とする。数値や名前は補間値として渡し、出典リンク・日時・強調を含む文章には`Trans`を使う。翻訳文字列や補間値を`innerHTML`へ渡さない。通常のReact描画でエスケープする。

翻訳機能はpresentationに閉じる。domain・application・infrastructureは表示言語を参照しない。APIは引き続き日本語の`detail`を返し、画面で既知メッセージを翻訳する。パスワード長・履修年度範囲を含むローカル検証は、原文にある数値を保って翻訳する。新しい未知のdetailは、意味を捏造せず原文を残す。

科目名、所属名、分類名、判定条件名、推薦理由、未確認理由、出典文書名・ページなどは原文を保持する。必修区分、成績の状態、判定状態、開講学年・学期などのUIラベルは翻訳する。英語化のためにDBのマスタや保存済み履歴を変更しない。

## 確認

`make frontend-check`、`npm --prefix frontend test`、`make build`を実行する。翻訳テストは初期言語・保存復元・ストレージ拒否・補間変数の対応・画面キーとAPIの既知detailの翻訳網羅・出典リンク・原文データの保持を確認する。

ブラウザーでは通常の開発DBではなく一時DBを使い、次を確認する。

- 英語ブラウザーでの初回表示、日本語選択後の再読み込み、ページタイトルと`html.lang`。
- 登録・ログイン・復旧の入力エラーと、表示中のエラーを残した言語切替。
- 所属選択・未保存成績・本人申告の回答を保った切替と、保存通知。
- ダッシュボード、条件別判定、判定保存と履歴、過去の結果。
- 読込み中・API失敗と再試行・検索0件・課程切替・狭い画面。
