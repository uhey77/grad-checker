# 2026年度の卒業・修了要件の照合状況

2026年度入学者を優先し、2026年度学生便覧と大学の公開資料を照合する。課程を選択できることや単位条件を計算できることは、卒業・修了要件の全項目を確認できることを意味しない。学籍や在学期間、大学による認定は成績データだけでは確定できない。

## 蒲田キャンパス学生便覧の照合

提供された「2026年度学生便覧（蒲田キャンパス）」はPDF 276ページ、SHA-256 `0fba087a3c9370bfae3c2405581cd98e01e7302dc1be916b500431c57bccf892`。原本はリポジトリに含めない。

- 看護学科の科目表（PDF 58〜61ページ、冊子56〜59ページ）と既存マスタの科目名・種別・単位は114行すべて一致。卒業要件はPDF 63ページ。保健師資格を取得する経路は指定科目と実技の選択条件を別途評価する。
- 臨床工学科の科目表（PDF 67〜69ページ、冊子65〜67ページ）と既存マスタは87行すべて一致。PDF 67ページでは基礎教育の12単位と自然科学の8単位は別々の必修条件で、合計20単位。選択も自然科学2単位以上とそれ以外4単位以上の両方が必要。卒業要件はPDF 70ページ。
- 臨床検査学科の科目表（PDF 94〜96ページ、冊子92〜94ページ）と既存マスタは86行すべて一致。卒業要件はPDF 97ページ。

既存の公開科目表には2024年度入学生用の表記があるため、上記は2026年度便覧の該当表との行単位の一致により確認した。科目名・種別・単位の一致は、入学年度ごとのあらゆる取扱いが同一である証拠ではない。科目ID、既存の成績、他の課程のマスタは変更しない。

## 現在の限界

- 学部の在学期間、進級・実習の先行条件、編入・認定等の個別事情をすべて自動確認する機能はない。入力した成績と登録済みの単位条件を使う参考結果であり、大学の正式な卒業認定ではない。
- 八王子4学部の他学部科目は、確認済みの対象とアプリの配分方針に限って算入する。未登録の算入対象は判定を停止する。蒲田の他学部や他大学の認定を網羅していない。
- 修士の在学・研究指導・論文審査等は本人申告を受けた参考判定であり、大学の正式な修了認定ではない。他研究科の単位認定は未対応。
- 博士後期4課程は専攻別の学位申請要件、英語プログラム3課程は科目と修了条件の対応を確認できていないため判定を停止する。大学公開の[英語科目一覧](https://www.teu.ac.jp/grad/english/major/admission.html)だけから、2026年度の全修了要件や日本語科目との同一性は確定できない。
- 適用入学年度は各シードの確認状態を保持し、未確認の年度や条件を推測して補わない。上記以外の課程についても、公式資料のすべての注記と個別事例を網羅した検証は完了していない。
